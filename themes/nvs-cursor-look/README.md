# nvs-cursor-look

Snapshot of the `nvs-cursor-look` theme component (locally authored, not a
remote theme — `remote_theme_id` is unset), exported from the `nitians` site's
database for version-control/review purposes. These files are **not** wired
up to sync automatically; the live theme is edited through Admin > Customize
> Themes, or via `Theme#set_field`/`save!` in a runner script. Re-export this
folder by hand after any further admin-side edit to keep it from drifting.
